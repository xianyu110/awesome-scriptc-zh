30 秒上手

npm install -g scriptc   # Node 24+
# 写好 hello.ts 后：
scriptc coverage hello.ts
scriptc run hello.ts
scriptc build hello.ts -o hello
./hello scriptc

截图

记住三件事

  • 需要 Node 24+ 安装编译器；产物可无 Node 运行
  • 实验性：先 scriptc coverage 再 build
  • 链接阶段准备好 clang / 平台 SDK
